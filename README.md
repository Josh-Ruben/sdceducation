# Shree Devi Group of Colleges Website
Premium editorial academic website inspired by the information architecture and polish of modern MIT pages, without copying MIT branding or content.

Static GitHub Pages-ready frontend: HTML/CSS/JS.
SDC information is based on official public SDC listings. Verify all course/eligibility details before production.
The SDC AI is a deterministic starter knowledge layer. For a production LLM, use a secure backend/serverless proxy; never expose an API key in browser JavaScript.
